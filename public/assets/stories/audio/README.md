# Background Music Placeholder

To enable background music functionality:

1. Add your background music file here as:
   `background-music.mp3`

2. Recommended specifications:
   - Format: MP3
   - Bitrate: 128-192 kbps
   - Duration: 2-5 minutes (it will loop)
   - Volume: Normalized to -14 LUFS
   - Style: Soft, ambient, non-intrusive

3. Free music resources:
   - https://www.bensound.com/
   - https://incompetech.com/
   - https://freemusicarchive.org/
   - https://www.youtube.com/audiolibrary

4. Make sure you have the rights to use the music!

## Testing

Once added, the background music will:
- Play when users click the music toggle (bottom-right corner)
- Loop continuously
- Auto-pause when story narration plays
- Remember user's play/pause preference
